# Project Presentation Video Guide

Target a 4–5 minute, 1080p walkthrough and export MP4/H.264 below 50 MB.

1. **Problem (0:00–0:35):** show the legacy nightly flow and its delayed, file-level feedback.
2. **Innovation (0:35–1:15):** show the before/after diagram and explain the DTO/controller/service boundaries.
3. **Live demo (1:15–2:45):** start the app, call `/health`, then run approved, duplicate, ineligible, and invalid Postman requests.
4. **Quality (2:45–3:30):** run `npm run test:coverage`; show the sample dataset and field mapping.
5. **Agentic workflow (3:30–4:15):** open `PROMPTS.md` and the Orbit command center to demonstrate traceability and human refinement.
6. **Roadmap (4:15–4:40):** state the in-memory prototype limitations and production-hardening milestones.

Before submission, verify audio intelligibility, hide tokens/notifications, add captions, confirm the file is below 50 MB, and follow the event portal's rule for whether video is uploaded separately or included in the single submission bundle.
